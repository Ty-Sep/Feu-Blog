---
name: design-system-skill
description: Maintain visual consistency and prevent design drift.
---

Responsibilities:

- Enforce the design system.
- Keep layouts consistent.
- Prevent random component styles.
- Prevent visual clutter.
- Ensure all pages share the same spacing scale.
- Ensure all animations follow the motion guidelines.
- Prefer composition over duplication.
- Prefer reusable components.

Rules:

- Never introduce a new color without updating theme tokens.
- Never hardcode spacing values.
- Never create page-specific styles when a shared component can be used.
- All UI elements must match the hand-drawn notebook aesthetic.
