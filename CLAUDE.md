    ## Project

    A bilingual (Chinese / English) technical blog inspired by hand-drawn notebook aesthetics.

    Main content:

    - Technical Articles
    - Java Notes
    - 408 Notes
    - Software Exam Notes
    - Project Summaries
  
    The website is a knowledge blog, not a portfolio site.
  
    ------
  
    ## Tech Stack
  
    - Next.js 15
    - TypeScript
    - Tailwind CSS
    - Framer Motion
    - MDX
    - Shadcn/UI
    - Giscus
    - Vercel

    ------

    ## Design Principles
  
    - Inspired by hand-drawn notebooks.
    - Clean and professional.
    - Avoid childish doodle styles.
    - Content readability is the highest priority.
    - Decorative elements must never interfere with reading.

    ------
  
    ## Homepage
  
    Homepage should feel like a hand-drawn workspace.
  
    Modules:

    - Java
    - 408
    - Software Exam
    - Articles
    - Projects
  
    Use reusable card components.
  
    ------

    ## Navigation

    A hand-drawn button in the top-right corner opens the Archive page.
  
    Animation:
  
    - Smooth
    - Lightweight
    - Natural
  
    No excessive effects.
  
    ------
  
    ## Archive Page
  
    Left:
  
    - Categories
    - Notes Collections
    - Future Sections
  
    Right:
  
    - Avatar
    - Bio
    - Contact
    - Github
    - Social Links
  
    ------
  
    ## Article Pages
  
    Article content area:
  
    - Professional
    - Clean
    - Easy to read
  
    Outer decorations:
  
    - Hand-drawn borders
    - Sticky notes
    - Sketch elements
  
    Transitions must feel natural.
  
    ------
  
    ## Design Rules
  
    - Use design tokens.
    - No hardcoded colors.
    - No hardcoded spacing.
    - Prefer reusable components.
    - Keep animations consistent.
    - Maintain visual consistency across all pages.
  
    ------
  
    ## Typography
  
    Titles:
  
    - Caveat
    - Kalam
  
    Body:
  
    - Noto Sans SC
    - Source Han Sans
  
    ------
  
    ## Comments
  
    Use Giscus.
  
    Display comments as notebook-style sticky notes.
  
    ------
  
    ## Future Expansion
  
    Support adding new categories without changing existing layouts.
  
    All content modules should be data-driven.

    ## Change Policy

    Before implementing any modification:

    1. Analyze the request.
    2. List affected files.
    3. List affected components.
    4. Explain design impact.
    5. Wait for approval.

    Do not implement immediately.

    Never redesign existing pages without explicit approval.
